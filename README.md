# Projeto de Ciência de Dados
## Análise Descritiva — Concorrência em Cotas Públicas (2016–2025)

Este projeto tem como objetivo desenvolver um website para apresentar uma análise descritiva utilizando dados reais de concorrência em cotas públicas da UEPG/UTFPR-PG entre os anos de 2016 e 2025.

O trabalho utiliza:
- HTML
- CSS (Bootstrap)
- JavaScript
- Chart.js

---

# Estrutura do Projeto

## index.html
Arquivo principal do website.

Responsável pela estrutura da página:
- títulos
- seções
- tabela
- gráfico
- análises

---

# Pasta /css

## style.css
Responsável pela aparência do site:

# Pasta /js

## script.js
Controla o funcionamento geral do site.

Responsável por:
- carregamento da página

---

## chart-config.js
Responsável pela configuração dos gráficos utilizando Chart.js.

Aqui ficam:
- cores das linhas

---

## data.js
Responsável por armazenar e organizar os dados utilizados no projeto.
